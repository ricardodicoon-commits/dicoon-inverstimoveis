# Dicoon Invest Imóveis — site

Site oficial da Dicoon Invest Imóveis: correspondente bancário, financiamentos, consórcios, seguros, investimentos e imóveis (Canoas/RS).

## Rodar no computador

```bash
npm install
npm run dev
```

## Publicar

Hospedado na Vercel, ligado a este repositório: cada envio para o branch `main` vai para o ar.

## Estrutura

- `src/pages/Site.tsx` — site público (uma página com seções)
- `src/pages/AreaCliente.tsx` — `/app`, aviso enquanto o CRM é reconstruído
- `src/config.ts` — telefone, e-mail, endereço e CNPJ
